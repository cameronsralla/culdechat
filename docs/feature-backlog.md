# Cul-de-Chat: Feature Backlog
Last Updated: September 30, 2026

Product features aimed at **meaningful neighbor interaction** — utility that leads to real-world connection. Status: **next** · **planned** · **later** · **parked** · **done** · **skip**

Engineering sequencing still lives partly in [backlog.md](./backlog.md). This file is the **product feature wishlist** driven by vision + marketplace research. Non-goals: [non-goals.md](./non-goals.md). Competitors: [competitive-landscape.md](./competitive-landscape.md).

---

## High leverage (prioritize)

These map to jobs neighbors already do on WhatsApp / FB Groups / Nextdoor — without copying engagement-maxxing.

| Item | Status | Job it serves | Notes |
|---|---|---|---|
| **Seeded purpose boards** | planned | Latch points at launch | Marketplace, Lost & Found, Recommendations, etc. Launch plan: seed boards **and** a few initial posts so the square isn’t empty |
| Post types / templates | planned | Lower blank-page friction | Intro, Lost & found, Free/For sale, Looking for recommendation, Help/ask — compose helpers on top of seeded boards |
| **Weekly digest** | planned | Reliable reach without scroll addiction | Email (and later in-app) “worth reading this week”; AI-assisted summary/draft OK — human/admin tone still matters |
| **About me / richer profiles** | planned | Discovery → real connection | Interests, short bio, “ask me about…” — gold for neighbors who wouldn’t otherwise bump into each other; ties to directory |
| Community calendar | planned | Coordinate in-person engagement | Events with date/time, list + calendar views; RSVPs as connection-validating signal |
| Events (structured) | planned | Turn intent into attendance | Overlaps calendar; RSVP / attendee count |
| Photos / media on posts | planned | Marketplace, lost items, proof, vibe | **All media types eventually**, gated by host resources / capability tiers (see vision) — not a permanent text-only product |
| Simple search (posts / people / boards) | planned | Findability | Towne/Nextdoor pain point |
| Polls | planned | Low-effort coordination | “Saturday 8 or 9?” |
| First-week / new-resident onboarding | planned | Best window to connect | Photo optional, join General, intro prompt, directory + about-me hint |
| Unread / useful activity signals | planned | Return for utility | Piece of a coherent **notification strategy** (deep-dive later) |
| Report → admin DM | planned | Civility without surveillance culture | Eng backlog; formal report table later |
